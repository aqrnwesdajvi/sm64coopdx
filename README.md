## Overview

sm64coopdx is the leading Super Mario 64 online co-op mod, enabling up to 24 players to explore, collect stars, and complete courses together in the same Super Mario 64 world in real time. Built on the sm64ex PC decompilation port, it adds a lobby system, host-configurable game rules, Discord Rich Presence, and a Lua modding API for custom mini-games and level modifications.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **sm64coopdx** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **24-Player Co-Op** | Up to 24 players simultaneously in the same SM64 world online |
| **Lobby System** | Host-configurable lobbies with rule sets, player counts, and privacy |
| **Discord Integration** | Rich Presence shows current level and player count to Discord friends |
| **Lua Mod API** | Extend co-op with custom mini-games and level modifications via Lua |
